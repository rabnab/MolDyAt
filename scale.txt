---  suitable only for noble gases
length scale = [m] distance in LJ_potential (r_m=1)
mass scale = [kg] typical gas e.g N = 14 u => mN2 = 28 1.66E-27 kg

const kb should be 1: kb = [J/K] --> kB T = 1/N sum(E_kin_i)
const eps should be 1: eps = [J] -->

E [Si] = E*eps;
T [Si] = E*eps/kb;
L [Si] = L*r_m;
M [Si] = m*mAr;

t [Si] = sqrt(mN2*r_m^2 / eps); --> time scale for interaction


d_dt x = d_d(tscale tau) x = 1/tscale d_dtau xau * r_m = r_m/t_scale *d_dtau xau
E_kin = eps * mau * vau^2/tau
T = eps/kb Tau --> Tau = 1/N sum ( E_kin_au)

d_dt x = d_d(tscale tau) x = 1/tscale d_dtau xau * r_m = r_m/t_scale *d_dtau xau
d_dt² x = d_d(tscale tau)² x = 1/tscale² d_dtau² xau * r_m = r_m/t_scale² *d_dtau² xau

d_dx LJ = 1/r_m d_dxau eps LJau = F = eps/rm Fau == mau *mN2 r_m/t_scale² *d_dtau² xau
    --> Fau = r_m/eps *r_m/r_m^2/mN2*eps d_dtau² xau = d_dtau² xau  
    --> Fau = d_dtau² xau
